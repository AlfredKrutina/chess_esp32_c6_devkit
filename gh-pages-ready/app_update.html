Mobile app version check

When you open Settings, the CzechMate app downloads app_update.json from the root of this site and compares the installed semver version with the latest_version field.

For the client, the JSON is always the source of truth. This page describes the field schema.

Location

app_update.json — the same content as in the repository at gh-pages-ready/app_update.json.

Schema

  • latest_version (string, required) — newest published version. Older installs show an update prompt.
  • min_supported_version (string, optional) — below this version a stronger update prompt is shown.
  • release_page_url (URL string, optional) — target of the download button. If omitted, the app uses its built-in default URL.

Example

{
  "latest_version": "1.7.4",
  "min_supported_version": "1.6.0",
  "release_page_url": "https://alfredkrutina.github.io/chess_esp32_c6_devkit/downloads.html"
}

After publishing a new app version, keep the JSON values in sync with flutter_czechmate/pubspec.yaml, commit the change to the repository, and deploy via GitHub Actions to the gh-pages branch.
