Detailed Description

PRIME LED FUNCTION FOR GAME TASK - Back Queue Hell.

RESOLUTION: Use prime LED call instead of xQueueSend(led_command_queue).

  • Back queue hell
  • No timing problems
  • Instant LED updates
Author
Alfred Krutina
Version
1.8.0
Date
2025-09-02

This module provides prime LED functions for game tasks without using queues. Eliminates queue hell and timing problems by calling the LED function directly. All functions are thread-safe thanks to the use of a mutex in led_task.
