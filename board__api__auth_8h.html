Detailed Description

Board REST API token (NVS) + HTTP Bearer check for sensitive endpoints.

Auth matrix (HTTP)

  • Public GET (No Bearer): eg /api/status, /api/board, /api/game/snapshot, /api/wifi/status, /api/system/firmware, /api/system/ota/status (onboarding).
  • Admin POST (/api/system/ota, /api/system/factory_reset, paths under /api/wifi/, …): a valid Bearer is always sufficient. If WEB_LOCK is on and Bearer is missing or invalid → 403 web_locked. If WEB_LOCK is off (default), POST from LAN will go through without a header (just like the open GET API).

Token: 32B random, in header as Authorization: Bearer <64 hex characters>.

BLE (see ble_task_conn_is_encrypted)

  • ota_start, ota_ble_begin, ota_ble_abort, ota_ble_status, wifi_sta_config, wifi_ap_set, factory_reset: require an active encrypted link (after SMP).
