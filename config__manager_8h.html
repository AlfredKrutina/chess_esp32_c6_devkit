Detailed Description

ESP32-C6 Chess System v1.8.0 - Config Manager Header.

This header defines the configuration management interface:

  • System configuration structure
  • Functions for configuration management
  • Error codes and constants
Author
Alfred Krutina
Version
1.8.0
Date
2025-08-24

Config Manager manages system configuration stored in NVS flash. Enables loading, saving and applying system settings (verbose mode, quiet mode, log level, timeout, echo).

esp_err_t config_manager_init ( void )

Initializes the config manager.

Initializes the NVS flash to store the configuration. NVS flash is already initialized in main.c init_console(), so this function only verifies availability.

Returns
ESP_OK on success, error code on failure
