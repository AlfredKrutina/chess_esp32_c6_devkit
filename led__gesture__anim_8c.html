Detailed Description

Wave, boot snake, shutdown chase, and pairing pulse.

Square orientation follows chess_pos_to_led_index(): row 0 is rank 1 (e1 is row 0, col 4), col 0 is the a-file. The column mirror inside that function is the wiring map; this file does not flip it.

The physical button sits on h1 (row 0, col 7). The wave origin is the center of that square. The snake starts there and crawls h1→a1, then a2→h2.

LED 72 (reset / gesture button) follows the same phase: orange while held, gold through the wave, green along the snake, white-to-off on shutdown, blue during pairing. Edges ease instead of popping one square per frame.

◆ led_gesture_start_wave()

bool led_gesture_start_wave ( const uint32_t  new_colors[64],
bool  inward 
)

Wave between the current board and new_colors.

Outward (inward == false) spreads from the button on h1 and covers the board. Inward plays that wave backwards: the current picture shrinks back into h1 and new_colors show from the far corner. The mode flag itself is not changed here. Fails if new_colors is NULL or another gesture is already running.

Parameters
new_colors64 LED-index colors for the picture left when the wave ends.
inwardtrue to run the wave from the far corner back to h1.
Returns
true if the wave started.
