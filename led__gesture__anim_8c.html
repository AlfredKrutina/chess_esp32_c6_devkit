Detailed Description

Wave, boot snake, shutdown chase, and pairing pulse.

Square orientation follows chess_pos_to_led_index(): row 0 is rank 1 (e1 is row 0, col 4), col 0 is the a-file. The column mirror inside that function is the wiring map; this file does not flip it.

The physical button sits just outside the board on the edge between a1 (row 0, col 0) and b1 (row 0, col 1). The wave origin is the midpoint of that edge, half a square off the board: (file 0.5, rank -0.5).

void led_gesture_note_release ( void  )

Button went up.

Cancels a forward snake (plays it backwards) or a shutdown that has not finished. A release during the reverse does nothing. Wave and pulse ignore the latch. The flag is stored even if the LED phase has not started yet.
