Detailed Description

Pause play when the physical board disagrees with the logical position.

JSON keys and Kconfig stay matrix_guard_* / CONFIG_CHESS_MATRIX_*. This module only decides pause, LED layers, and resync. It does not merge reed GPIO with Hall I2C.

◆ game_squares_guard_handle_command()

void game_squares_guard_handle_command ( const chess_move_command_t *  cmd)

Handle GAME_CMD_SQUARES_GUARD.

Action 0 clears the pause and notifies clients. Any other action copies the lifted and dropped masks and enters the pause, unless the guard is disabled or a special mode is active (those paths abort the baseline and do not stay paused). NULL or a different command type is ignored.

Parameters
cmdCommand from the game queue.
