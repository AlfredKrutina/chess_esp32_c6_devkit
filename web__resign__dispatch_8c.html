Detailed Description

App resignation for HTTP (POST /api/game/resign) and BLE ({"cmd":"resign"}).

Body (both transports): optional {"side":"white"|"black"}. Without "side" the side on move resigns. With "side" the board refuses when the other side is on move, so a stale app snapshot cannot resign the wrong colour. The game itself ends in game_task (GAME_CMD_RESIGN → game_resign_from_app), the same path as the 10 s king-lift resignation.
