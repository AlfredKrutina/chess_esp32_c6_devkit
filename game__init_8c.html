◆ game_reset_game()

void game_reset_game ( void  )

Resets the game to its default state.

Reset the game to its initial state.

This function resets the game to its default state. Erases all strokes, resets game states and initializes a new game.

The function resets:

  • Game state on IDLE
  • Current games on WHITE
  • Number of moves to 0
  • All castling flags
  • En passant status
  • History of move
  • Error recovery status

void game_start_new_game ( void  )

Start a new game.

This function will start a new chess game. Initializes the inbox, resets all states and prepares the game for play.

Features:

  • Initializes the inbox to the default state
  • Resets all game states
  • Set the first game to WHITE
  • Stop all animations
  • Updates LED feedback
  • Increase the number of games
