Detailed Description

OTA transports: HTTPS from the Internet (STA + CA bundle), HTTP from the LAN (e.g.

phone on AP 192.168.4.x hosts .bin — STA not needed), BLE OB stream.

State, journal and boot confirmation live in the ota_guard component; this file only moves bytes into the inactive slot and reports phases to the guard: receiving → verifying (esp_ota_end + project check) → rebooting (boot slot switched). Success is reported only by the next boot after the new image confirms itself.
