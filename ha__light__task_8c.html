Detailed Description

HA Light Task - Home Assistant RGB Light Integration via MQTT.

autotoc_md25

WHAT DID THIS FILE DO?

This task integrates the box as an RGB light into the Home Assistant via MQTT. After connecting to the WiFi STA, the board automatically switches to HA mode after 5 minutes idleness. In HA mode, all LED boards behave as one RGB light.

Modes:

  • GAME MODE: LED displays chest (default)
  • HA MODE: All 64 LEDs as RGB light controlled via HA (after 5 min of inactivity)

Automatic switching:

  • GAME -> HA: After 5 minutes of no activity (figure movement or game command)
  • HA -> GAME: Immediately upon detection of piece movement (PICKUP/DROP)

◆ HA_MQTT_TASK_STACK_BYTES

#define HA_MQTT_TASK_STACK_BYTES   (6 * 1024)

esp-mqtt uses this when task.stack_size is 0.

Custom menuconfig is off, so mqtt_config.h falls back to 6144. xTaskCreate needs one internal block of that size. In buffer is 512, out buffer is HA_MQTT_PAYLOAD_MAX. URI is mqtt:// so mbedtls content buffers are not taken (CONFIG_MBEDTLS_SSL_IN_CONTENT_LEN is 16384 and does not fit a 14 KiB block). tcp_snd is the sdkconfig send-buffer cap the broker socket grows toward.
