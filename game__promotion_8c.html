void game_check_promotion_needed ( void  )

Checks whether graduation is possible and updates the LED indication of the buttons.

This function checks all pesce on promotion squares (row 0 and 7) and updates the promotion_state. Next, it updates the LED indication of all promotion buttons (green = active, blue = inactive).

The function should be the steering wheel:

  • After each turn
  • After graduation
  • When initializing the game

LED indication:

  • Green (0,255,0): Graduation is possible for the current player
  • Blue (0,0,255): Graduation is not possible
  • Reset button (LED 72): Always green

◆ game_process_promotion_button()

void game_process_promotion_button ( uint8_t  button_id)

Handles the graduation button event.

Parameters
button_idButton ID (0-7 for promotion, 8 for reset)

Button Mapping:

  • 0-3: White promotion (Queen, Rook, Bishop, Knight)
  • 4-7: Black promotion (Queen, Rook, Bishop, Knight)
  • 8: Reset button

There are only 4 physical buttons (QUEEN, ROOK, BISHOP, KNIGHT), which maps to 0-3 or 4-7 according to current_player.
