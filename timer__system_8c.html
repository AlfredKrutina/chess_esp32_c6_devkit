Detailed Description

ESP32-C6 Chess System v1.8.0 - Timer System implementation.

This component implements the time system for a chess game:

  • Accurate time measurement with ESP32 timer API
  • Thread-safe operations with case
  • Different types of time checks
  • JSON API for web interface
  • NVS persistence settings
Author
Alfred Krutina
Version
1.8.0
Date
2025-01-XX

Timer system uses ESP32 timer API for accurate time measurement. All operations are thread-safe using mutex. Supports standard time controls and custom settings.
