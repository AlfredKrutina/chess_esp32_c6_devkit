Detailed Description

Pure commander / token-slot rules.

No ESP, NVS, or BLE calls.

One writer. Up to three remembered devices. A Wi-Fi command needs a token from one of those slots. While a BLE commander is up, only that device's token may write. Otherwise the token that holds the seat may write, and a different valid token is told the board is busy.
