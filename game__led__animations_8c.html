Detailed Description

ESP32-C6 Chess System - Advanced LED animation.

Complete implementation of advanced LED animations for the Sacha system:

  • 5 endgame animations including wave animation
  • Soft animations for figurines and buttons
  • Full error handling
  • RGB optimization for nice color transitions
Author
Alfred Krutina
Version
1.8.0
Date
2025-09-04

This module contains all advanced LED animations for the sach system. Contains endgame animations, smooth effects and optimized color transitions. All animations are smooth and memory efficient.
