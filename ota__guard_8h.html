Detailed Description

OTA state machine and boot guard shared by all OTA transports.

Single source of truth for the state reported to the app (GET /api/system/ota/status, BLE ota_ble_status, GET /api/system/firmware).

Boot side (called from main):

  • ota_guard_boot_early(): first thing in app_main, no NVS needed. Arms the confirm deadline when the running image is PENDING_VERIFY and counts crash resets in RTC memory.
  • ota_guard_init(): after NVS init. Resolves the outcome of the previous OTA attempt from the NVS journal + otadata and performs the crash-loop fallback to the other slot.
  • ota_guard_confirm_if_healthy(): from the main loop. Confirms the image (esp_ota_mark_app_valid_cancel_rollback) only after a stable uptime with an OTA transport up.
  • ota_guard_on_init_failure(): from safe-mode branches.

Transport side (ota_update.c): begin → progress → verifying → validate → rebooting, or aborted / error. Success is reported only after the new image confirmed itself on the next boot.

void ota_guard_on_init_failure ( const char *  what)

Safe-mode hook.

PENDING_VERIFY image → rollback + reboot (does not return). Confirmed image with a valid other slot → counts toward crash loop and restarts (does not return). Otherwise returns and the caller keeps its UART safe mode.
