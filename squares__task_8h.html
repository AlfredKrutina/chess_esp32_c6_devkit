Detailed Description

ESP32-C6 Chess System v1.8.0 - Matrix Task Header.

This header defines the interface for the matrix task:

  • Scan of 8x8 reed switch matrix (default, CONFIG_CHESS_MATRIX_INPUT_GPIO_REED)
  • I2C Hall occupancy scan (CONFIG_CHESS_MATRIX_INPUT_I2C_HALL): reads raw ADC pairs from 4x STM32 slaves, runs the ported POC classification (energy + hysteresis + debounce) and fills squares_state with 0/1 occupancy. Stable Hall-detected piece type and color are available via squares_get_hall_piece_type/color; game_task uses them for legality when I2C Hall input is enabled.
  • Stroke detection and validation
  • Generation of matrix events
  • Time-multiplexed GPIO control
Author
Alfred Krutina
Version
1.8.0
Date
2025-08-24

The matrix task is responsible for detecting pieces on the help box 8x8 reed switch matrix. It scans the matrix every 20ms and detects when a player picks up or places a piece. It communicates with the game task via queues.

Hardware:

  • 8x8 reed switch matrix
  • Row pins: GPIO10-11,18-23 (outputs)
  • Column pins: GPIO0-3,6,14,16-17 (inputs with pull-up)
  • Time-multiplexed with buttons
