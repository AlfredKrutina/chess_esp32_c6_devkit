Detailed Description

STM32 ROM I2C bootloader for the four Hall segments (AN4221).

One segment is out of reset at a time. When the bus is shared with Hall, hall_i2c_squares_init() must run first. Builds with the bootloader Kconfig off return ESP_ERR_NOT_SUPPORTED from the esp_err_t entry points.
