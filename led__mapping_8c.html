Detailed Description


Correct mapping of the box position to the LED index (serpentine layout)

This module contains functions for converting drawer positions to LED indexes. Uses a serpentine layout for optimal LED distribution on the box.

Serpentine layout LED signs are laid out in a serpentine pattern: a1,b1,c1,d1,e1,f1,g1,h1,h2,g2,f2,e2,d2,c2,b2,a2,a3,b3,c3... This layout enables easy conversion of positions to LED indexes.

Converts the box position to an LED index.

Layout: a1,b1,c1,d1,e1,f1,g1,h1,h2,g2,f2,e2,d2,c2,b2,a2,a3,b3,c3... The box is rotated along the Y axis (a1 is at h1 position).

colColumn (0-7 where 0=a, 7=h)
