Detailed Description

ESP32-C6 Chess System - LED Mapping function.

This module provides functions to convert between drawer positions and LED indices. Uses a serpentine layout for optimal LED distribution on the box.

Author
Alfred Krutina
Version
1.8.0
Date
2025-08-24

LED Mapping module converts box positions (row, column) to LED indexes and vice versa. It uses a serpentine layout for the serpentine layout of the LED strip:

  • Even rows: a->h (left to right)
  • Odd rows: h->a (right to left)

Example serpentine layout:

Row 1: LED 0, 1, 2, 3, 4, 5, 6, 7 (a1->h1)
Row 2: LED 15, 14, 13, 12, 11, 10, 9, 8 (h2->a2)
Row 3: LED 16, 17, 18, 19, 20, 21, 22, 23 (a3->h3)
