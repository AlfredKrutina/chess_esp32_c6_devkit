Detailed Description

LED State Manager implementation.

This module manages the status of the LED system and provides advanced LED control function. Allows layering effect and management display priorities.

Author
Alfred Krutina
Version
1.8.0
Date
2025-09-06

LED State Manager is a central system for LED state management. Allows layering of different effects, manage priority and advanced function for controlling the LED system.
