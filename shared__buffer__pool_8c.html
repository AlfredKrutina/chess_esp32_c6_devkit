Detailed Description

ESP32-C6 Chess System - Implementation of Shared Buffer Pool.

Replaces the malloc/free call with a pre-allocated buffer pool for:

  • Elimination of heap fragmentation
  • Improved memory allocation performance
  • Memory leak prevention
  • Memory usage check
Author
Alfred Krutina
Version
1.8.0
Date
2025-01-27

Shared Buffer Pool is a system for effective memory management in the system. Instead of dynamic allocation, it uses pre-allocated buffers, which eliminates heap fragmentation and improves performance. It contains 4 buffers with a size of 2KB.
