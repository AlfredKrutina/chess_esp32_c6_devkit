Detailed Description

Visual Error System implementation.

This module provides visual error indication and user guidance. Shows error states through LED animations and provides text messages with pretext.

Author
Alfred Krutina
Version
1.8.0
Date
2025-09-06

Visual Error System is a system for visual error indication in storage system. It uses LED animations to show the error type and provides text messages with instructions for solving the problem.

Gets the LED color for the given error type.

Each type of error is assigned a specific color for visual distinction:

  • INVALID_MOVE: red
  • PIECE_BLOCKING: orange
  • CHECK_VIOLATION: purple
  • NO_PIECE: yellow
  • WRONG_TURN: blue
  • etc.
