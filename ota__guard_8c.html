Detailed Description

OTA state machine, NVS journal of the last attempt and boot guard.

Power-loss model:

  • Image bytes go only into the inactive slot (esp_ota_get_next_update_partition).
  • otadata is switched (esp_ota_set_boot_partition) only after esp_ota_end verified the whole image and the app descriptor matches this project.
  • The bootloader (CONFIG_BOOTLOADER_APP_ROLLBACK_ENABLE) boots a freshly switched image as PENDING_VERIFY; any reset before esp_ota_mark_app_valid_cancel_rollback() makes it fall back to the previous slot.
  • The journal (NVS blob, atomic per write) records the phase of the last attempt so the next boot can report receiving→aborted, verifying→aborted / rolled_back, rebooting→verifying / success / rolled_back truthfully.
  • Crash-loop counter lives in RTC memory (no flash writes, cleared on power-on).
