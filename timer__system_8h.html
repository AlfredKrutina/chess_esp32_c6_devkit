Detailed Description

ESP32-C6 Chess System v1.8.0 - Timer System component.

This component manages the time system for the chess game:

  • Different types of time checks (bullet, blitz, rapid, classical)
  • Accurate time measurement with ESP32 timer API
  • Thread-safe operations with case
  • Integration with game task
  • Web API for time control
Author
Alfred Krutina
Version
1.8.0
Date
2025-01-XX

Timer system provides complete time control for chess game. Supports standard time controls and custom settings. All operations are thread-safe and optimized for ESP32.
