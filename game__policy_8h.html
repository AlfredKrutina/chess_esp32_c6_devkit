Detailed Description

Compile-time gameplay gates.

Kconfig is the source of truth.

Each helper returns a menuconfig flag (or a conjunction of flags). Call sites stay thin. Runtime state is not stored here, except game_policy_error_recovery_enter_lock(), which sets the recovery latch when locking is enabled.
