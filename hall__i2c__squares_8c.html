◆ hall_i2c_squares_readings_usable()

bool hall_i2c_squares_readings_usable ( void )

Whether occupancy readings are safe to compare with the logical board.

Hall: true once every square has a baseline that was not taken from a magnet and the trimmed-mean ring is full. A square that has not named its piece yet still counts, so one unsettled magnet cannot keep the guide off. Reed builds have no Hall baseline and always return true.

Returns
true when a scan may be trusted for guard / restore.

void hall_i2c_squares_set_logical_empty ( const uint8_t empty_squares[64],
const uint8_t piece_types[64] )

Tell Hall which squares the logical game says are empty.

Only those squares may be zeroed from live ADC. Occupied squares reuse a stored empty baseline or a provisional copy of confirmed empty squares. Reed builds ignore the buffer.

Parameters
empty_squares64 bytes, 1 = logically empty. NULL is ignored.
piece_types64 bytes, Hall type of the logical piece, 0 if empty. NULL treats every occupied square as a king (widest stray field).
